- summary: Implements Cubid-Me/cubid-monorepo#136 on the SDK side, as a new package rather than RN-safe primitives inside `@cubid/react` (the two draw with different host components and different peers). `@cubid/react-native` sits on `@cubid/browser` like `@cubid/react` does: `CubidProvider` / `useCubidClient`, `EmailOtpForm` and `PhoneOtpForm` as the same one-time-code flows drawn with `View`, `Text`, `TextInput` and `Pressable` (no DOM, no `react-dom`), and `CubidProfileDetails`, one component that collects what a profile is missing — email, phone, name, picture, location — each `required`, `optional` or `skip`, asking only for what `known` does not already cover, and handing back one result. Location granularity is an input (`none` / `rough` / `approximate` / `exact`): the app's `readPosition` is called with the granularity so it can ask for coarse permission only, and the reading is rounded (about 11 km / 1 km / as read) before it leaves the device. Name and picture have no Cubid write API yet, so they are returned for the app to store; email and phone persist as stamps through `persistStamp`. Wired into vitest (node + jsdom projects, coverage), `tsconfig.base.json` paths, the API reference generator and manifest, the README package matrix, and a changeset.
- validation: `pnpm --filter @cubid/react-native typecheck` clean; `pnpm exec eslint packages/react-native` clean; `pnpm exec vitest run --config vitest.config.ts packages/react-native`: 2 files, 5 tests pass (the jsdom tests stand in for react-native with `src/react-native.mock.tsx`); `pnpm --filter @cubid/react-native build` (tsup, cjs + esm + d.ts) ok; `node scripts/build-api-reference.mjs` regenerated `docs/reference/api/react-native.json` and the manifest. Not run: the full acceptance harness; a device smoke in an Expo app (RendR will do that once published).
- follow-ups: The Passport-side contract for storing a name, a picture and a location at a chosen granularity (today only the `address` stamp via the hosted page, and the read-only `fetch_*_location` calls) — tracked in the #136 thread; a hosted email page as the fallback the issue also asked for; publishing the first version.
